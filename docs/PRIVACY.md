# AskBridge 隐私说明

AskBridge 是本机 Windows 快捷操作层，不是 AI 服务。它只把用户主动框选的截图准备到用户选择的 AI 网页编辑区，最终发送必须由用户在网页中确认。

## 本地处理的数据

- 截图先以 RGBA 保存在进程内存中；专用 Chrome 上传需要路径时，短暂写入数据目录的 `Temp` 子目录，完成、失败或取消后删除。
- 设置保存在数据目录的 `config.json`。
- 专用 Chrome 登录状态由 Chrome 保存在 `BrowserProfile`。AskBridge 不读取密码、验证码、Cookie、Local Storage、历史对话或网页正文。
- 只有用户点击截图工具条中的“复制”，选择“通用粘贴”，或“专用 Chrome 优先”在确认尚未写入任何内容后触发安全降级时，AskBridge 才会把当前截图写入系统剪贴板。
- “通用粘贴”读取可见候选窗口的窗口类、标题、所属进程的可执行文件名和 Windows 应用包标识，用于确认目标属于受支持的浏览器或 AI 桌面客户端，并排除名称相同的其他应用。为把 Ctrl+V 送入明确的输入区并确认附件结构，UI Automation 还会读取控件类型、可聚焦/启用/密码/离屏状态和边界矩形，并在唯一编辑器附近的有界区域比较图片和分组数量；不读取控件名称、控件值、窗口正文、账号或完整进程路径。这些页面结构属性和计数只用于本次判断，不写入日志；应用包标识同样不写入日志。

## 不会执行的操作

- 不调用模型 API，不运行本地模型，不在本地渲染回答。
- 不点击发送按钮，不模拟发送按键；`auto_submit` 始终为 `false`。
- “通用粘贴”及其安全降级会通过逐级窗口激活并检查前台归属，只在目标确实取得前台后模拟一次 Ctrl+V 粘贴快捷键；不模拟回车或任何发送操作，不读取窗口正文。若专用 Chrome 可能已经插入文字或附件，自动降级会被禁止，以免重复粘贴。
- 不连接日常 Chrome 用户目录。
- 不保存截图历史、问题历史、聊天 ID 或对话正文。
- 不使用浏览器扩展、Electron、Tauri 或常驻 Python 进程。
- WebView2 只渲染本地截图工具条，不承载或读取 AI 供应商网页。
- 正式程序不监听本地 HTTP 服务，不把 Chrome 调试端口开放到局域网。
- 不要求管理员权限，不安装全局键盘钩子，不修改系统代理，不关闭安全软件，不禁用 Chrome sandbox。

## 日志

日志位于 `<AskBridge 数据目录>\logs\askbridge.log`。允许字段包括时间、版本、请求 ID、投递模式、供应商 ID、阶段、耗时、错误类别、布尔结果、候选窗口类和可执行文件名。只记录可执行文件的基本名称，不记录完整路径。禁止记录问题原文、截图或 Base64、剪贴板、窗口标题、页面 HTML、对话、Cookie、Local Storage、令牌、账号信息、CDP 完整正文、调试端口和完整聊天 URL。

## 数据位置、升级和卸载

开发工作区使用 `D:\AskBridge\data`。便携或安装版本默认使用程序旁的 `data`，也可通过绝对路径环境变量 `ASKBRIDGE_DATA_DIR` 覆盖。升级保留 `data`；卸载默认保留配置和专用 Chrome 资料，只有用户明确选择删除数据时才会移除。

## 程序更新联网

- AskBridge 启动后以及每 24 小时通过 HTTPS 读取官方 GitHub 仓库的最新 Release 元数据，也允许用户从托盘手动检查。检查请求不包含截图、问题、配置、日志、账号或浏览器资料。
- 只有用户确认安装后，AskBridge 才下载 Release 中与版本号严格匹配的 `Setup.exe`、`SHA256SUMS.txt` 及其签名文件 `.sig`。下载地址必须属于 `wanghongyu666qiang/AskBridge` 官方仓库，哈希清单必须通过程序内嵌公钥的 Ed25519 签名校验，安装包必须通过大小和 SHA-256 校验。这些请求同样不包含任何用户数据。
- 下载文件只写入 AskBridge 数据目录的 `Updates` 子目录。更新完成或程序再次启动后会清理已使用或遗留的安装包；更新过程保留整个 `data` 目录。
- 更新程序等待当前 AskBridge 正常退出后才替换程序文件，成功后重新启动；校验或启动安装器失败时不会修改当前程序。

## 第三方网页

网页内容准备完成后，AI 供应商将按其自身隐私政策处理用户最终确认发送的内容。AskBridge 不代表这些供应商，也不改变其账号、数据保留或内容政策。
