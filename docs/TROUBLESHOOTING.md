# AskBridge 故障排查

运行数据默认位于程序旁的 `data`；开发工作区使用 `D:\AskBridge\data`。只有绝对路径环境变量 `ASKBRIDGE_DATA_DIR` 可以覆盖该位置。

## 程序没有托盘图标

1. 在任务管理器确认是否已有 `askbridge.exe`。AskBridge 只允许一个实例。
2. 检查 `data\logs\askbridge.log` 的最后一条事件。
3. 若配置损坏，程序会保留 `config.corrupt-*.json` 并恢复默认配置。
4. Debug 构建可从 PowerShell 运行 `target\debug\askbridge.exe` 查看加载器错误。

## 快捷键没有反应

1. 从托盘打开“设置”，确认对应快捷键已启用并点击“应用更改”。
2. 若组合被其他程序占用，AskBridge 会保留旧绑定，请换用其他带修饰键的组合。
3. “暂停全局快捷键”开启时，从托盘恢复即可。

## 截图工具条没有出现

1. 确认系统安装了 Microsoft Edge WebView2 Runtime。
2. WebView2 初始化失败时程序会显示功能较简化的原生工具条，仍可复制、取消、切换模型和继续。
3. `Esc` 取消截图，`Enter` 使用当前模型继续；右键也会取消。

## 图片没有上传

1. 在设置的“浏览器”页为 ChatGPT 选择“AskBridge 专用 Chrome”。桌面网页端可以复用现有登录，但不能自动上传截图。
2. 首次使用专用 Chrome 时先在该独立浏览器中登录供应商。
3. 页面存在多个同等可信附件控件、没有唯一 PNG 文件控件或页面结构变化时，AskBridge 会停止并提示错误，不会误报成功。
4. 所有路径都不会点击发送按钮；内容准备后必须由用户手动确认发送。

## 专用 Chrome 无法启动或连接

1. Chrome 路径留空可自动检测，也可以在设置中选择现有的 `chrome.exe`。
2. 点击“检查连接”只会连接 AskBridge 专用 Chrome，不会连接日常 Chrome。
3. 若提示配置正在使用，先正常关闭所有由 AskBridge 启动的 Chrome 窗口。
4. 不要添加 `--no-sandbox`、`--disable-gpu` 或固定远程调试端口。

## 多显示器偏移

截图使用虚拟桌面坐标并支持负坐标副屏。若混合 DPI 下出现偏移，请记录显示器相对位置和缩放比例，但不要提交真实截图内容。

## 更新检查或安装失败

更新功能需要能直接访问 `api.github.com` 与 `github.com`；公司代理或防火墙可能拦截这些请求。

- 「更新签名校验失败」：下载的校验清单与维护者离线签名不一致，更新被拒绝且当前程序未被修改。请稍后从官方 Releases 页面重新发起检查。
- 「发布缺少 AskBridge-x.y.z-SHA256SUMS.txt.sig」：该 Release 资产不完整，说明发布流程异常，请等待修复版本。
- 「更新安装包 SHA-256 校验失败」：下载内容损坏或不完整，重新执行一次更新即可。
- 「安装程序无法启动」：已下载并通过校验的安装包仍在本机，从托盘菜单再次选择「安装」即可重试，无需重新下载。
- 更新过程中设置窗口会显示下载进度；若长时间停在某个百分比，多为网络问题，取消后重试。

## 提交诊断信息

可以提交程序版本、Windows/Chrome 版本、失败阶段和经过人工检查的日志。不要提交问题原文、截图、剪贴板内容、网页 HTML、Cookie、令牌、账号或完整聊天 URL。
